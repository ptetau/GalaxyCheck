# Test review of S1 (targets, CI, and the benchmark suite), round 1

- major: [tests] test_001_S1_R19_test_step_names_both_targets_in_a_matrix_or_a_framework_argument A workflow whose net11.0 leg runs no test passes, because each test project of GalaxyCheck.sln targets only net10.0. The test reads only the text of the workflow. Fix: also read each test project of GalaxyCheck.sln and require both net10.0 and net11.0 in its target frameworks, or run `dotnet test --framework net11.0 --list-tests` on the solution and require at least one test.
- major: [tests] test_001_S1_R19_test_step_runs_for_net10_and_net11 The test asserts that the workflow holds no `net8.0`. The spec forbids a net8.0 assembly in the packages, not the text `net8.0` in the workflow. Fix: remove that assertion.
- major: [tests] test_001_S1_R62_the_only_sources_are_nuget_org_and_one_repository_folder A `nuget.config` with no `<clear />` passes, but then the restore also reads each source of the machine, so nuget.org and the folder are not the only sources. Fix: require a `<clear />` element before the two `add` elements in `packageSources`.
- minor: [tests] test_001_S1_R61_matrix_holds_the_three_operating_systems A workflow that names `windows-latest` or `macos-latest` only outside the matrix (for example in a `runs-on` of another job or a comment) passes. Fix: read the `os` list under `matrix:` and require the three values in it.
- minor: [tests] test_001_S1_R46_case_holds_values_per_second_and_bytes_per_value_for_both_libraries This test and test_001_S1_R47_case_holds_the_ratios_of_current_to_baseline are `[Theory]` methods. interface.md says each test is a `[Fact]` method. Fix: loop over the six case names in one `[Fact]`, and name the case in the failure message.
