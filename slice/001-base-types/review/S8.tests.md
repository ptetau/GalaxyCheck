# Review of the tests of S8 (the xunit v3 and TUnit packages), round 1

- major: [tests] test_001_S8_R23_tunit_falsified_property_is_one_failed_test_with_counterexample_and_replay The test builds its reference from `Property.Assert` of the core library, which has the line `Reproduction: <replay>`. Then it checks only the text before the replay string, which is `Reproduction:`. So a TUnit package that uses the default text of the core library passes, though the acceptance line asks for the text of GalaxyCheck.Xunit (`[Replay("...")]` on its own line, after blank lines). A package that leaves out the replay string also passes, because no check reads the replay string. Fix: compare the whole message with the message that GalaxyCheck.Xunit gives for the same property and seed, as the xunit v3 test does with its reference project. At the least, check that the message holds `[Replay("<replay>")]` and the counterexample line.
- major: [tests] test_001_S8_R22_tunit_public_attributes_exist_with_the_options_of_xunit The metadata reader adds each property of a type, internal ones too. So the test requires each internal property of the GalaxyCheck.Xunit attribute, for example the skip reason, the runner, and the nullable option values, to exist in the TUnit attribute with the same name. The spec asks only for the public options. A correct TUnit package that names its internal state differently fails. Fix: read only the properties that have a public getter or setter, or compare with the fixed list of options of interface.md.
- minor: [tests] test_001_S8_R26_sample_test_fails_and_lists_the_sampled_values The test checks only that the message holds "5". A message that lists no values but holds the digit 5 elsewhere also passes. Fix: check for a line such as `Sample[0]: 5`, or compare with the text that GalaxyCheck.Xunit gives for the same sample.
- minor: [tests] test_001_S8_R22_tunit_has_property_test_attribute_and_property_arguments_attribute The test checks only that the constructor of `PropertyArgumentsAttribute` has one parameter. A constructor that takes one `object` value, not a `params` array, also passes, and then a row with two values does not compile. Fix: check that the parameter is an `object[]` with the `params` attribute, or run a sample with a two-value row.
- minor: [tests] test_001_S8_R22_tunit_pack_holds_net10_and_net11_and_no_other_target The name says "no other target", but the test checks only that the two targets exist. Fix: rename the test, or check that the list of targets is exactly `net10.0` and `net11.0`.
- minor: [tests] test_001_S8_R24_tunit_each_falsified_form_fails Each falsified form fails on its first test case, and the test checks only the outcome. A run that fails for a different cause, for example an error that the adapter gives before it runs the property, also passes. This applies to test_001_S8_R24_each_form_that_holds_passes_and_each_falsified_form_fails too. Fix: check that each failure message holds `Falsified after`.
- minor: [tests] test_001_S8_R22_pack_holds_lib_folders_net10_and_net11 The test classes of slice S8 are named `S10_PackageTests`, `S10_RunTests`, `S11_PackageTests`, and `S11_TUnitRunTests`, and the sample folders are `samples/S10` and `samples/S11`. Fix: rename the classes to `S8_...`. The sample folders can stay if a rename breaks the paths.
