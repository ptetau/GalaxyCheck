# Review of the tests of S6 (property features), round 1

- major: [tests] test_001_S6_R56_discard_check_names_check_and_suppression No test covers the acceptance line for a property whose precondition is false for each input. No test checks that such a property fails with `TestFunctionNeverRuns` and a message that names the check, and no test checks that suppressing that check by name stops it. A version that never trips the check, or that ignores its suppression, passes the suite. Fix: add `test_001_S6_R56_never_runs_check_names_check` and `test_001_S6_R56_suppressed_never_runs_check_does_not_fail`, with `Property.Precondition(false)`.
- major: [tests] test_001_S6_R36_passed_report_lists_label_share The test accepts any share from 0 to 100. A version that counts the label wrongly, for example one that reports 100% or 0% for "even", passes. The property over `Gen.Int32().Between(0, 9)` with 100 iterations is exhaustive, so the share must be exactly 50. Fix: assert that `Labels["even"]` is 50 and that the report holds "50% even".
- major: [tests] test_001_S6_R40_sync_function_over_limit_fails_fast_with_limit_and_input The generator has only the value 7, so each test case waits. A version that puts the limit on the whole run, and not on one test case, also passes. The async test has the same gap. Fix: use a generator of several values where only 7 waits, with enough fast test cases that the whole run takes longer than 100 ms when no case waits. Also assert that a property whose test cases each take less than the limit passes, even when the whole run takes longer than the limit.
- minor: [tests] test_001_S6_R36_failure_report_lists_label_share The test checks only that a share with "even" appears. A version that lists a wrong share passes. Fix: assert the share that the fixed seed gives, or use a check of the result whose share can be computed from the inputs that ran.
- minor: [tests] test_001_S6_R56_suppressed_discard_check_does_not_fail The test asserts only that no `HealthCheckException` is thrown. A version that still fails the property for the same cause, with another exception, passes. Fix: assert that the check does not fail the property, for example with a filter that keeps 5% but never gives up in a row, so that `Check` returns a result that is not falsified.
- minor: [tests] test_001_S6_R40_sync_function_over_limit_fails_fast_with_limit_and_input The message check `Contain("7")` can match the replay string or the iteration count. Fix: assert the counterexample line, for example "Counterexample: 7".
- minor: [tests] test_001_S6_R40_xunit_property_attribute_over_limit_fails_with_same_message The acceptance line asks for the same message, but the test checks only "Timed out after 100 ms" and not the input. Fix: also assert the input of the test case in the message.
- minor: [tests] test_001_S6_R39_list_counterexample_has_compiling_expression The test converts each element and compares the sequence, so an expression that makes an array or a list of longs passes. Fix: assert that the result is a `List<int>` equal to the value.
- minor: [tests] test_001_S6_R36_passed_report_lists_label_share The test class is named `S8_PropertyFeaturesTests`, the namespace is `S8Samples`, and the sample folder is `S8`. The test names hold S6, so the scripts work, but the names point a reader at the wrong slice. Fix: rename them with S6.
