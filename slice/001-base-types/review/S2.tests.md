# Review of the tests of S2 (a core that is 100 times faster), round 1

- major: [tests] test_001_S2_R51_each_readme_csharp_block_compiles_unchanged_and_runs The test never runs a block. Each README block is a class with no entry point, so the console build fails with CS5001, and the test skips the run. A wrong version passes when a README property fails at run time. For example, the `[Replay("AgEKAgkA")]` string might no longer decode, or a `[Property]` method might throw a generator error. Fix: compile each block as a library. Then call each method that has `[Property]`, `[Sample]`, or `[Replay]`, and run the returned property with the library's check method, with the replay string of the `[Replay]` attribute where there is one. Assert that no generator error and no replay error occurs.
- minor: [tests] test_001_S2_R48_sample_record_throughput_ratio_is_at_least_100 The test reads only the ratio. A wrong version that simplifies the shared case code passes, for example a record without the string or the DateTime member, or an easier shrink property for "shrink list of ints". Fix: assert through reflection on the benchmark assembly that the record of the case has an int, a string, a DateTime, and a Guid member.
