# Review of the tests of S2 (a core that is 100 times faster), round 2

- minor: [tests] test_001_S2_R48_sample_record_throughput_ratio_is_at_least_100 The test reads only the ratio. A wrong version that simplifies the shared case code passes, for example a record without the string or the DateTime member, or an easier shrink property for "shrink list of ints". Fix: assert through reflection on the benchmark assembly that the record of the case has an int, a string, a DateTime, and a Guid member.
- minor: [tests] test_001_S2_R51_each_readme_csharp_block_compiles_unchanged_and_runs The test skips each annotated method that has parameters, and the count check asks for only 1 run in each block. A wrong version passes when a second property of a block fails at run time, or when a property with parameters throws a generator error. Fix: count the methods with `[Property]`, `[Sample]`, or `[Replay]` in each block, and assert that the test runs each of them, or fails on one that it cannot run.
- minor: [tests] test_001_S2_R51_each_readme_csharp_block_compiles_unchanged_and_runs The helper `Close` is never called, and the helper `type0` has a name that does not say what it returns. Fix: delete `Close`, and rename `type0` to say that it tells whether a block has an annotated method.
