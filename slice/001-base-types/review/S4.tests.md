# Review of the tests of S4 (time types, containers, and automatic generation), round 1

- minor: [tests] test_001_S4_R11_datetimeoffset_failing_property_shrinks_to_origin The property always fails, so the first counterexample is already near the origin. A wrong version whose DateTimeOffset shrinking stops near the minimum or the maximum of the range passes. Fix: add a test with the property "the value is before 2010-01-01T00:00+00:00" and the default generator, and assert the counterexample 2010-01-01T00:00+00:00, with several seeds.
- minor: [tests] test_001_S4_R32_interface_gives_each_concrete_type The test uses the interface only at the top level, and each implementation has a public constructor. A wrong version that fails for `List<IShape>`, for `(int, IShape)`, or for an interface with a type that has only a private constructor passes. Fix: add a test that samples `Gen.Create<List<IShape>>()` and checks that a `Circle` appears, and a test with an extra implementation that has only a private constructor.
- minor: [tests] test_001_S4_R33_union_gives_each_case The sample uses the union only at the top level. A wrong version that fails for `List<Pet>` passes. Fix: also sample `Gen.Create<List<Pet>>()` in the sample.
- minor: [tests] test_001_S4_R11_timespan_min_and_max_appear The class names name the wrong slices: `S5_TimeTests`, `S5_ContainerTests`, `S6_AutomaticTests`, `S6_Net11Tests`, `S6_ReplayTests`, `S6_TargetsTests`, the helper `S6Support`, and the namespace `S6Shapes`, and the sample folder `samples/S6`. Fix: rename each to S4.
