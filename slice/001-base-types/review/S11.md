# Review of S11 (agent experience), round 1

- major: [correctness] src/GalaxyCheck.Xunit/Core/Internal/FailureMessage.cs:142 `Quote` wraps the filter in double quotes and escapes only `\` and `"`, so bash still expands `$(...)` and backticks in the rerun command. An NUnit generic fixture `[TestFixture(typeof(int))] class G<T>` gives `dotnet test --filter "FullyQualifiedName=Ns.Sub.G`1[[System.Int32, System.Private.CoreLib, ...]].GP"`, and bash stops with "unexpected EOF while looking for matching ``'". A method named `Test $(touch /tmp/x) `id`` (an F# name, or one from Reflection.Emit) gives a command that creates the file and runs `id` when an agent pastes it; I ran this through bash with `echo` in place of `dotnet test`. The `test` field of the generic fixture also holds the assembly-qualified type name, and no filter matches it. Fix: quote with single quotes and write each `'` as `'\''`, build the class part from the name that the adapter reports (NUnit `G<Int32>`), and add a slice test with a generic fixture and a name that holds `$`, a backtick, and a quote.
- major: [requirement] src/GalaxyCheck.Xunit/Core/Internal/FailureMessage.cs:91 Known limit 3 (the rerun of a data row or fixture matches by part of the name) breaks R63 (machine-readable failures) more than the limit states: the command runs other methods and other classes, not only other rows. NUnit `Row(1)` gives `FullyQualifiedName~Ns.Sub.C.Row`, which also runs `Row2(1)`. The fixture `Fx(1).F` gives `FullyQualifiedName~Ns.Sub.Fx&FullyQualifiedName~.F`, which runs 4 tests, `F2` included. MSTest `Row (1)` also runs `Row2 (1)`. An exact filter works: `FullyQualifiedName=Ns.Sub.C.Row\(1\)` and `FullyQualifiedName=Ns.Sub.Fx\(1\).F` each run 1 NUnit test, and `FullyQualifiedName=Ns.Sub.C.Row` runs only the 2 rows of the MSTest method. In TUnit, `ClassName` (line 115) drops the outer class, so the test `Ns.Sub.C+Inner.Q` gets `/RevTUnit/Ns.Sub/Inner/Q`, which runs 0 tests. `/RevTUnit/Ns.Sub/C+Inner/Q` runs the test. Fix: use `=` with the NUnit name and escaped parentheses for a row or fixture, use `=` with the method name for an MSTest row, use the nested name `C+Inner` for TUnit, and add slice tests for a row, a fixture, a method name that is a prefix of another, and a nested class.

- major: [correctness] src/GalaxyCheck/Internal/FixHint.cs:18 Several `Fix:` lines give advice that is wrong for the error. `Gen.TimeSpan().From(TimeSpan.FromHours(2)).Until(TimeSpan.FromHours(1))` and the same call on `DateOnly` get `.GreaterThanEqual(4).LessThanEqual(5)`, which `IRangeGen<T>` does not have.
