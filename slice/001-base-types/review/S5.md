# Review of S5 (text, realistic data, and recursive generators), round 1

- major: [security] src/GalaxyCheck/Gens/PatternGen.cs:215 `PatternRepeat.MaxLength` multiplies with no overflow check, so nested fixed repeats wrap to a negative length and pass the 100000-character limit. `((((((a{1000}){1000}){1000}){1000}){1000}){1000}){10}` passes the parse, then the generator grows one string to about 4.2 GB of memory for 8 s before it throws. A literal records no choice, so the limit of 4M choices does not stop it. Fix: saturate the product (when the length of the node is above the cap divided by the count, return the cap), so that each such pattern gets the "longer than 100000 characters" error.
- major: [requirement] src/GalaxyCheck/Gens/PatternGen.cs:632 R34 (each value matches the pattern): `\0` always gives one NUL character, but .NET reads `\0` and up to two more octal digits as one octal escape. For the pattern `\012`, each value is NUL followed by "12", and no value matches (.NET expects one newline). Fix: read up to two more octal digits after `\0`, or refuse the octal escape with an error that names it.
- major: [requirement] src/GalaxyCheck/Gens/ReflectedGenHelpers/ReflectedGenHandlerContext.cs:43 R54 (`Gen.Create<T>()` for a type that refers to itself ends) is met only when a collection is between the type and itself. `class Linked { public int V { get; set; } public Linked? Next { get; set; } }` still gives "detected circular reference on type 'Linked' at path '$.Next'". Fix: give a nullable member of a type that is already in the history null or a value, and null at the depth limit of 5, so that a linked list generates. A member that cannot be null and has no collection on its path can keep the error.
- major: [security] src/GalaxyCheck/Gens/ReflectedGenHelpers/ReflectedGenHandlers/DictionaryReflectedGenHandler.cs:57 The values of a dictionary use the member name `[*]`, so `IsCircularWithoutCollection` now lets them through, but this handler has no depth limit. `class DNode { public Dictionary<string, DNode> Kids { get; set; } }` makes `Gen.Create<DNode>()` recurse with no end and crash the process with a stack overflow. Before the slice, the same type gave a circular-reference error. Fix: give the dictionary handler the same depth check and count limit as the collection and array handlers, or use a member name that the circular check does not treat as a collection.
- minor: [security] src/GalaxyCheck/Gens/PatternGen.cs:816 `ToChars` stores each character of a class in an array. A 10000-character pattern of 700 classes `[\u0000-￿]` allocates about 92 MB to build the generator. Fix: keep the ranges, and pick a character by an index into the ranges.
- minor: [requirement] src/GalaxyCheck/Gens/PatternGen.cs:215 Shrinking of a repeat of alternatives keeps a longer alternative when a shorter one would do: for `(a|bb|ccc){2,}` and the property "the length is below 6", the counterexample is `bbaabb`, not `aaaaaa`. The value is still a match, so R34 holds.
