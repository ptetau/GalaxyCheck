# Review of S5 (text, realistic data, and recursive generators), round 2

- major: [architecture] src/GalaxyCheck/Gens/ReflectedGenHelpers/ReflectedGenHandlers/CompositeReflectedGenHandler.cs:38 A cycle with no member that can end it now gets null in a non-nullable member at depth 5. For `class NonNull { public NonNull Next { get; set; } }` in a nullable-enabled project, each of 100 values is exactly 5 deep and ends in a null `Next`. The library reads NullabilityInfo so that a non-nullable reference member never gets null, and this value breaks that contract with no error. No finite value of such a type exists, so R54 ("ends") is met better by an error. Fix: when the member's NullabilityInfo says NotNull, keep the error "detected circular reference on type '<T>' at path '<path>'". Give null at the limit only when the state is Unknown (a nullable-oblivious project).
- minor: [requirement] src/GalaxyCheck/Gens/PatternGen.cs:194 Shrinking of a repeat of alternatives keeps a longer alternative when a shorter one would do. For `(a|bb|ccc){2,}` and the property "the length is below 6", the counterexample is `bbbbbb`, not `aaaaaa`. The value is still a match, so R34 holds.
