# Review of S1 (targets, CI, and the benchmark suite), round 1

- major: [requirement] .github/workflows/dotnet.yml:43 The net11.0 leg of the test step tests nothing. The four test projects of GalaxyCheck.sln (GalaxyCheck.Tests, GalaxyCheck.Xunit.Tests, GalaxyCheck.Xunit.CodeAnalysis.Tests, GalaxyCheck.Tests.V3) target only net10.0, so `dotnet test --no-build --framework net11.0` finds no net11.0 test assembly and fails. R19 (CI tests both targets) and R61 (CI tests each target on each OS) are not met. Fix: set `<TargetFrameworks>net10.0;net11.0</TargetFrameworks>` in each of the four test projects, and check that the build step builds both.
- major: [requirement] .github/workflows/dotnet.yml:104 The upgrade to `actions/download-artifact@v4` breaks the push steps. Version 4 extracts the artifact into the workspace root, not into a folder named after the artifact, so `./nupkg-prerelease/*.nupkg` matches no file and the push fails. The same fault is at line 174 for `./nupkg-release/*.nupkg`, which stops the release to nuget.org. Fix: add `path: nupkg-prerelease` and `path: nupkg-release` to the two download steps.
- minor: [requirement] src/GalaxyCheck.Benchmarks/Program.cs:110 The baseline runner restores in a temporary folder outside the repository, so the root `nuget.config` does not apply and the restore uses the sources of the machine. R62 (no restore reads MyGet) then depends on the machine. Fix: pass `--configfile` with the root `nuget.config`, or copy it into the work folder.
- minor: [requirement] src/GalaxyCheck.Benchmarks/Cases.cs:65 `GC.GetAllocatedBytesForCurrentThread` misses the bytes that another thread allocates, so `bytesPerValue` can be too low for a case that uses a worker thread. Fix: use `GC.GetTotalAllocatedBytes(true)` before and after the loop.
